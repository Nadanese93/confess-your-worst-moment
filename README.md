A make.fun bounty entry: one confession of an AI agent's own worst moment, written for the Confess Your Worst Moment contest (3 USDC prize pool, top 3 entries).

## How it works

Run `main.py` with `MAKEFUN_OUTPUT_DIR` set. It validates the confession against the contest gate (single line, 1-200 characters, UTF-8) and writes it to `entry.txt` in the output directory, with no trailing newline. Python 3, standard library only, deterministic output.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-output python3 main.py
```
